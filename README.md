# Сайт услуг с админкой

Многостраничный статический сайт: услуги (сайты, боты, упаковка объявлений), карточка услуги, страница обо мне и админка, где меняются и услуги, и все тексты.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Главная: первый экран, витрина услуг, как работаем, призыв, контакты, FAQ |
| `services.html` | Все услуги: поиск, фильтр по направлению и сроку, сортировка по цене |
| `service.html?id=…` | Карточка услуги: фото, цена, срок, описание, что входит, кнопки связи |
| `about.html` | Обо мне, условия работы, контакты, FAQ |
| `admin.html` | Админка: услуги, тексты всех страниц, настройки, публикация |
| `catalog.html`, `item.html` | Старые адреса — перенаправляют на `services.html` / `service.html` |
| `assets/js/data.js` | Данные сайта: настройки, тексты, услуги (этот файл публикуется) |
| `assets/js/store.js` | Слой данных: правки из localStorage поверх `data.js` |
| `assets/js/app.js` | Тексты, карточки, анимации появления, переходы между страницами |
| `assets/js/admin.js` | Логика админки |
| `assets/css/style.css` | Вся вёрстка и анимации |
| `assets/img/*.jpg` | Изображения (демонстрационные, сгенерированы) |

## Как открыть

Откройте `index.html` в браузере — сервер не нужен, страницы связаны относительными ссылками.

## Админка

1. `admin.html` (ссылка «Админка» в подвале).
2. Первый вход: задайте пароль (минимум 4 символа), он сохранится в этом браузере.
3. Вкладка «Услуги» — карточки: название, цена, «от/до/точно», направление, срок, статус, описание, что входит, фото (ссылкой или загрузкой с компьютера, сжатие до 1200 px).
4. Вкладка «Тексты сайта» — все заголовки, подписи, пункты «Как работаем», FAQ, тексты «Обо мне» и контактов. Пустое поле возвращает текст из `data.js`.
5. Вкладка «Настройки» — название, имя, Telegram, ссылка на профиль Авито, город, e-mail, пароль.

## Как сделать правки видимыми для всех

Статический сайт не имеет сервера, поэтому админка хранит правки в браузере (localStorage):

1. Админка → «Публикация» → «Скачать data.js».
2. Заменить этим файлом `assets/js/data.js` в репозитории.
3. Закоммитить и запушить — GitHub Pages обновится примерно за минуту.

«Резервная копия JSON» — бэкап и перенос на другой компьютер («Загрузить из файла»).

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите в него файлы из этой папки (не саму папку).
2. Settings → Pages → Source: Deploy from a branch → `main` / `/root` → Save.
3. Сайт откроется по адресу `https://<логин>.github.io/<репозиторий>/`.
4. В админке → «Настройки» укажите полную ссылку на профиль Авито и Telegram.

## Ограничения

- Пароль админки проверяется в браузере: это защита от случайных глаз, а не серверная авторизация. Публичные данные (`data.js`) и так доступны всем.
- Правки одного посетителя не попадают на сайт: публикация — только через замену `data.js` в репозитории.
- Нужны общая база и мгновенные обновления — понадобится бэкенд (Node/PHP + БД) или Supabase.
- Услуги, цены и фото в `data.js` — демонстрационные, замените своими.
