# Сайт услуг — одна страница

Всё на одной странице `index.html`: один адрес, один файл для публикации. Админка встроена в ту же страницу и открывается по `Ctrl + Alt + A` или кликом по «© 2026 ЕВГЕНИЙ» в подвале.

## Структура

| Файл | Что это |
|---|---|
| `index.html` | Весь сайт: первый экран, услуги с фильтром, как работаю, почему удобно, призыв, контакты, FAQ + модалка услуги + админка |
| `assets/js/data.js` | Данные: настройки, все тексты, услуги (этот файл публикуется) |
| `assets/js/store.js` | Правки из localStorage поверх `data.js` |
| `assets/js/app.js` | Тексты, карточки, модалка услуги, анимации появления |
| `assets/js/admin.js` | Админка: услуги, тексты, настройки, публикация |
| `assets/css/style.css` | Вёрстка, анимации, модалки |
| `assets/img/*.jpg` | Изображения (демонстрационные) |
| `_old/` | Прежние отдельные страницы — не используются, можно удалить |

## Админка

- Открыть: `Ctrl + Alt + A` в любом месте страницы или клик по копирайту в подвале.
- Первый вход: задайте пароль (минимум 4 символа), он хранится в браузере.
- «Услуги» — добавить, изменить, удалить; цена, «от/до/точно», срок, фото, что входит.
- «Тексты» — заголовки, подписи, шаги, FAQ, контакты, подвал. Пустое поле возвращает текст из `data.js`.
- «Настройки» — название, имя, Telegram, ссылка на Авито, город, e-mail, пароль.
- «Публикация» — скачать `data.js`, бэкап JSON, импорт, сброс.
- Закрыть: `Esc`, крестик или «Выйти».

Правки сразу видны на странице в этом браузере. Чтобы их увидели посетители, нужен файл `data.js` в репозитории (см. ниже).

## Публикация (когда понадобится)

1. Админка → «Публикация» → «Скачать data.js», заменить им `assets/js/data.js` в репозитории.
2. GitHub: репозиторий → Settings → Pages → Branch: `main`, папка `/ (root)`.
3. Адрес будет один: `https://<логин>.github.io/<репозиторий>/`.

Сейчас сайт нигде не опубликован.

## Ограничения

- Пароль админки проверяется в браузере — это защита от случайных глаз, не серверная авторизация.
- Правки в админке не попадают к другим посетителям сами: публикация только через замену `data.js`.
- Для общей базы и мгновенных обновлений нужен бэкенд или Supabase.
- Услуги, цены и фото в `data.js` демонстрационные — замените своими.
