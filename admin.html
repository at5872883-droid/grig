Управление сайтом

Здесь меняются услуги, цены и все тексты на страницах. Правки сразу видны в этом браузере; чтобы их увидели посетители — выгрузите data.js во вкладке «Публикация» и замените файл в репозитории.

Сейчас сайт показывает демонстрационные данные из data.js. Замените услуги и тексты своими, затем опубликуйте файл.

Как сделать правки видимыми для всех

  1. Нажмите «Скачать data.js».
  2. Откройте папку сайта в репозитории на GitHub.
  3. Замените файл assets/js/data.js скачанным.
  4. Закоммитьте изменения — GitHub Pages обновится за минуту.

Загрузить из файла

Подойдёт data.js или JSON-бэкап. Текущие правки в браузере будут заменены.
